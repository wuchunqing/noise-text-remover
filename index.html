Blank lines vs duplicate lines

Blank-line removal deletes empty rows (and, here, whitespace-only rows). Duplicate removal keeps one occurrence of each repeated line — by default the first, or the last if you enable that option (useful for timestamped logs where the newest entry should win).

  • Trim for comparison treats apple and  apple  as the same duplicate without rewriting every line.
  • Trim each line actually rewrites output by stripping leading/trailing spaces.
  • Ignore case treats Apple and apple as duplicates, similar to advanced modes on Small Study Tools / Toolonic-style removers.

Filter & join tips

  • Use Contains to drop comment markers or junk tokens quickly.
  • Use Regex for patterns like ^# (lines starting with #) or \d{4}-\d{2}-\d{2}.
  • Invert filter keeps only matching lines — handy for extracting a subset.
  • Join turns a cleaned column into a single comma/pipe/tab-separated string for spreadsheets or code arrays.

FAQ

Is my text uploaded to a server?

No. All cleanup runs in your browser with JavaScript. Your lists never leave this tab — the same privacy idea used by modern duplicate-line removers.

Does duplicate removal change line order?

No, unless you choose a sort option. The tool keeps the first (or last) occurrence and preserves the relative order of remaining unique lines.

Are empty lines always deleted?

Only when “Remove blank / whitespace-only lines” is enabled. Turn it off if you need to keep paragraph spacing.

What is “trim before duplicate comparison”?

It compares lines after stripping leading/trailing spaces for matching purposes, but keeps the original spacing of the kept line unless you also enable “Trim each line”.

Can I remove lines that contain a word?

Yes. Set Filter mode to Contains (or Starts with / Ends with / Exact / Regex), enter the match text, and optionally invert to keep only matches.

How do I get a comma-separated list?

Clean blanks/duplicates first, then enable “Join remaining lines” and pick Comma + space (or another separator).
